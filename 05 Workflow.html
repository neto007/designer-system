Interactions

drag_from_palette

Drag a node from the right palette onto the canvas. Drop target shows a ghost outline + cyan dotted border.

connect_handles

Click‑drag from an output handle to an input handle. Edge color follows the source node's neon. Invalid connections turn red.

execute_run

Active node pulses purple, completed nodes get a green checkmark badge, errored nodes flip to red border + dashed edge.
