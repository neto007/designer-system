// 06.01

Voice principles

terminal · precise · zero fluff
01

Talk_like_a_terminal

Senior engineer mid-debug. snake_case identifiers, mono ids, prefixed verbs.

02

Verbs_over_features

Create_agent, not "Agent management". Run, not "Execute action".

03

Errors_state_then_fix

Name what failed, then how to recover. Never apologise; never speculate.

04

No_excitement

No exclamation marks. No emoji. No "Oops!" or "Yay!". The system is a tool, not a friend.

05

Numbers_are_data

Always show units, currency, and precision. 412 ms beats "fast".

// 06.04

Tone in practice

Do · write_this_way
  • > Agent_deleted · agt_01HRY8ZX2N removed
  • > 12_tools_attached · 4 require approval
  • > Connection_failed · check MCP server at :8080
  • > Run_complete · 47 records · 412 ms
Don't · sound_like_marketing
  • > "Wow! Your agent is ready 🎉"
  • > "Unleash the power of AI orchestration!"
  • > "Oops! Something went wrong."
  • > "We're sorry, please try again later."

focus_visible

Every interactive element shows a 2 px purple ring offset by the background — never outline:none without a replacement.

// pattern
:focus-visible {
  outline: none;
  box-shadow: 0 0 0 2px var(--ds-bg),
                       0 0 0 4px var(--ds-purple);
}
