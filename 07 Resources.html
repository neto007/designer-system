// 07.02

Quickstart

3 ways to consume the system
option_a · vanilla css

For static sites, marketing, embeds.

/* 1. import once */
@import url("./ds/tokens.css");

/* 2. use anywhere */
.btn {
  background: var(--ds-purple);
  box-shadow: var(--ds-glow-md-purple);
}
option_b · tailwind

For React / Vue projects using Tailwind v3+.

// tailwind.config.js
import shieldai
  from './ds/tailwind-preset.js'

export default {
  presets: [shieldai],
  content: ['./src/**/*.tsx'],
}
option_c · style_dictionary

For multi-platform pipelines (web + iOS + Android).

// build.cjs
const sd = require('style-dictionary')
sd.extend({
  source: ['ds/tokens.json'],
  platforms: { css: { ... }, ios: { ... } }
}).buildAllPlatforms()

Governance

how the system evolves
// owners

Platform_team

Owns the core: tokens, foundations, and the components in this library. Reviews all token-level changes.

// contributors

Surface_squads

Each product surface (Chat, Workflow, Studio) can propose new patterns via RFC, ship behind a flag, then promote to the kit.

// review_cadence

Bi_weekly_council

Token freezes ship on major releases. Component additions ship weekly. Bug fixes ship anytime.

// proposing a change
Open an issue in evolution-api/shieldai-ds with the rfc label. Include screenshots, the problem statement, and at least one alternative considered.
